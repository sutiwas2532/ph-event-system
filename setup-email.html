เปิดโปรเจกต์ใหม่ใน Google Apps Script

ล็อกอินด้วยบัญชี Google ที่ต้องการใช้ส่งอีเมล (แนะนำอีเมลบริษัท) แล้วกดสร้างโปรเจกต์ใหม่

เปิด script.google.com →
2

คัดลอกโค้ดนี้ไปวางแทนโค้ดเดิมทั้งหมด

ในหน้าต่างที่เปิดขึ้น จะมีไฟล์ Code.gs อยู่แล้ว — ลบข้อความเดิมออกให้หมด แล้ววางโค้ดนี้ จากนั้นกด Ctrl/Cmd + S เพื่อบันทึก

Deploy เป็น Web app

  
    
    
  1. กดปุ่ม Deploy มุมขวาบน → New deployment
    2. 
    
  2. กดไอคอนฟันเฟือง ⚙️ ข้าง "Select type" → เลือก Web app
    3. 
    
  3. ช่อง Execute as เลือก Me
    4. 
    
  4. ช่อง Who has access เลือก Anyone (สำคัญมาก ถ้าเลือกอย่างอื่นระบบจะส่งไม่ได้)
    5. 
    
  5. กด Deploy → Authorize access → เลือกบัญชี → หากขึ้นเตือน "Google hasn't verified" ให้กด Advanced → Go to … (unsafe) → Allow
    6. 
    
  6. คัดลอก Web app URL ที่ได้ (ลงท้ายด้วย /exec)
    7. 
  

  
คำเตือน "unverified" เป็นเรื่องปกติของสคริปต์ที่เราเขียนเอง เพราะยังไม่ได้ส่งให้ Google ตรวจ ไม่ใช่ความเสี่ยงด้านความปลอดภัย
